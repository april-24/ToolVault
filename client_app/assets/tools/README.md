# Tool photos

The resident app loads tool photos from this folder. The current catalog uses these exact filenames:

| Tool | Filename |
|---|---|
| 4-step safety ladder | `step_ladder.jpg` |
| Cordless drill-driver kit | `cordless_drill.jpg` |
| Wet & dry vacuum | `wet_dry_vacuum.jpg` |
| Carpet & upholstery cleaner | `carpet_cleaner.jpg` |
| Adjustable pressure washer | `pressure_washer.jpg` |
| Household steam cleaner | `steam_cleaner.jpg` |
| Folding hand truck | `hand_truck.jpg` |
| Furniture moving kit | `furniture_moving_kit.jpg` |
| Laser distance measurer | `laser_measure.jpg` |
| Self-leveling laser level | `laser_level.jpg` |
| Wall stud & wire detector | `stud_finder.jpg` |
| Folding workbench | `folding_workbench.jpg` |
| Manual drain auger | `manual_drain_auger.jpg` |
| Portable dehumidifier | `dehumidifier.jpg` |
| Ground-reach window cleaning kit | `window_cleaning_kit.jpg` |

Use JPG files and keep each image reasonably compressed (ideally under 500 KB). Square images around 800 × 800 px work well in the three-column cards; 2000 × 2000 px also works, but can increase app load size. The app crops each photo to fill its image area. If a file is missing or has the wrong name, the card shows that tool's icon instead.
